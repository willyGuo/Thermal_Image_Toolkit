RAW Full Quality Score Guide

判讀原則：所有 Score 為 0～100，越高越好。此方法屬於 No-Reference、 同場景相對比較指標，不是絕對 PASS / FAIL 規格。RAW 評分使用原始位深資料， 內部正規化到 0～1 後進行分析。

目前整體流程

Original RAW ↓ Normalize to 0~1 ↓ Bilateral Filter ↓ Base Layer + Detail Layer ↓ Sobel Gradient + 9×9 Local Std ↓ ┌──────────────────┬──────────────────┐ │ Flat Mask │ Edge Mask │ │ │ │ │ Adaptive Gray │ Sharpness │ │ Clustering │ Detail SNR │ │ ↓ │ Halo │ │ Connected │ ↓ │ │ Components │ Detail Clarity │ │ ↓ │ │ │ Region 1...N │ │ │ ├ Noise σ │ │ │ └ Uniform σ │ │ └──────────────────┴──────────────────┘ ↓ Flat Cleanliness / Thermal Uniformity + Contrast / Clipping / Artifact ↓ Total Score

1. Flat Region：Adaptive Gray Clustering

新版重點：不再把 Flat pixel 固定切成 8 個 Gray Bands。 現在會根據本張影像 Flat pixel 的實際 Histogram，自動決定灰階 Cluster 數量與邊界。

1.1 Flat candidate 怎麼找

先對 Base Layer 計算 Sobel Gradient 與 9×9 Local Standard Deviation：

Flat Gradient Threshold = clip(P35(Gradient), 0.004, 0.020)
Flat Std Threshold = clip(P50(LocalStd), 0.008, 0.035)
Flat Mask = low Gradient AND low LocalStd

另外會把 Edge Mask 膨脹成 guard，盡量避免邊緣 transition / ringing 被誤當成 Flat noise。

1.2 Adaptive Gray Clustering 怎麼做

Flat pixels ↓ 取 Base level 的 P1 ~ P99 ↓ 建立 128-bin Histogram ↓ 1-D Gaussian Smooth (σ = 2) ↓ 找 Significant Peaks ↓ 移除彼此太接近的 Peak ↓ 相鄰 Peak 中間找最低 Valley ↓ Valley = Cluster Boundary ↓ Adaptive Cluster 0...N
步驟目前做法目的
P1～P99 只用 Flat pixel 主要灰階範圍建立 Histogram。 避免極少量極端值影響分群。
Histogram 預設 128 bins。 保留足夠灰階結構，又不讓單一 DN noise 造成太多小峰。
Smoothing 1-D Gaussian，σ = 2。 抑制小型 histogram ripple。
Peak Detection Peak 必須是 local maximum，且具最低 histogram support。 只保留真正有代表性的亮度 population。
Peak Merge Peak 之間必須保有最小距離。 避免同一片寬廣表面被拆成很多群。
Valley Split 相鄰有效 Peak 之間找最低 Histogram Valley。 用場景本身的亮度分布決定 Cluster 邊界。

Cluster 數量不是固定值。 某張圖可能只有 2 群，另一張可能有 4、5、6 群。 目前設定 最多 8 個 Cluster，只是防止過度分群，不代表一定會產生 8 群。

1.3 為什麼 Adaptive 比固定 8 Bands 好

固定 8 BandsAdaptive Gray Clustering
固定每一段灰階範圍切割。 根據實際 Histogram 自動決定邊界。
同一表面可能剛好跨 Band 邊界而被硬拆開。 同一亮度 population 比較有機會保留在同一 Cluster。
場景只有 2 個主要亮度區，也仍然硬切成多個 Band。 場景有幾個主要亮度 population，就形成幾個有效 Cluster。

1.4 Cluster 後仍要做 Connected Components

Gray Cluster 只代表「亮度接近」，不代表空間上是同一個物體。因此每一個 Adaptive Cluster 還會再做：

cv2.connectedComponentsWithStats(..., connectivity=8)

使用 8-connectivity，可連接上下、左右與斜對角相鄰 pixel。

Adaptive Cluster 2 ↓ 可能同時包含： 左牆 + 右牆 + 地板的一小塊 ↓ 8-connectivity Connected Components ↓ Region A = 左牆 Region B = 右牆 Region C = 地板

每個有效 Region 最小面積：

minimum_area = max(96, ceil(ImagePixels × 0.0015))

過小的碎片會被排除，避免小型誤分割 Region 支配 Worst score。

2. Flat Cleanliness

每個有效 Flat Region 都各自計算高頻 Noise：

Detail = Original - Base

Noise σ = 1.4826 × median(|Detail - median(Detail)|)

這裡使用 MAD Robust Sigma，不是直接對原始灰階做 Standard Deviation。

2.1 Region 聚合

假設每個 Region 都已得到一個 noise_sigma：

聚合項目計算方式用途
Typical Noise 依 Region Area 加權的 P50。 代表大部分有效 Flat Area 的典型 noise。
Worst Noise 各有效 Region Noise 的 P80，不按 Area 加權。 避免大面積乾淨天空掩蓋較小但較差的牆面。

2.2 Noise 轉成分數

Typical Noise Score = 100 × exp(-TypicalNoise / 0.025)
Worst Noise Score = 100 × exp(-WorstNoise / 0.025)

Robust Noise Score = 65% × Typical + 35% × Worst

2.3 Impulse Noise

MAD 對極少數 hot / cold pixel 不敏感，因此另外利用 3×3 Median residual 找 isolated impulse，並限制 Connected Component 最大為 4 pixels。

Flat Cleanliness = 85% × Robust Noise Score + 15% × Impulse Control

高分代表：平坦區顆粒少，而且少量孤立 hot/cold pixel 也受到控制。

3. Thermal Uniformity

Uniformity 主要看較低頻的局部不均與固定條紋，不是 factory NUC 的 MinDN / MaxDN 規格。

Broad Base = GaussianBlur(Base, σ = 5)
Uniform Residual = Base - Broad Base

每一個 Adaptive / Connected Region 都各自計算：

Uniform σ = 1.4826 × MAD(Uniform Residual)

3.1 Typical / Worst

Typical Uniformity = Area-weighted P50
Worst Uniformity = Region P80 (unweighted)

Typical Uniformity Score = 100 × exp(-Typical / 0.020)
Worst Uniformity Score = 100 × exp(-Worst / 0.020)

3.2 Banding Control

另外從 Flat 區檢查 Row / Column banding。固定垂直條紋通常會反映在 Column profile， 固定水平條紋則會反映在 Row profile。

Banding Score = 100 × exp(-BandingSigma / 0.012)

Banding 越明顯 → Banding Sigma 越大 → Banding Score 越低。

3.3 Thermal Uniformity 最終分數

Thermal Uniformity = 50% × Typical Uniformity Score + 30% × Worst Uniformity Score + 20% × Banding Control

高分代表：各 Flat Region 都較平，而且水平 / 垂直 fixed-pattern stripe 較少。

4. Detail Clarity

4.1 Sharpness

對 Base Layer 使用 3×3 Sobel Gradient，Edge Region 的平均 Gradient 作為 Edge Strength。

Sharpness Score = clip(EdgeStrength / 0.16 × 100)

Sharpness 高代表邊緣變化快，但單看 Sharpness 可能把 Noise amplification 誤認為細節提升。

4.2 Detail SNR

Edge Detail = mean(|Detail| at Edge Mask)
Reference Noise = max(Typical Flat Noise, 1/255)
Detail SNR = Edge Detail / Reference Noise

Detail SNR Score = clip(DetailSNR / 5 × 100)

Detail SNR 高代表真正 Edge / Detail 明顯高於 Flat Noise。

4.3 Halo Penalty

RAW Full 使用 edge-normal overshoot / undershoot 檢查 Halo：

Halo Penalty = clip((HaloRatio - 0.10) / 0.50 × 100)

4.4 Detail Clarity 最終分數

Detail Clarity = 50% × Sharpness + 50% × Detail SNR - 8% × Halo Penalty

高分代表：邊緣銳利、細節高於 Noise，而且不是靠過度 sharpening 製造 halo。

5. Contrast Quality

Contrast Span = P99 - P1
Span Score = clip(ContrastSpan / 0.60 × 100)
Entropy Score = clip(EntropyBits / 7 × 100)

Contrast Quality = 70% × Span Score + 30% × Entropy Score

加入 Entropy 是避免只靠少量極端 pixel 把 P1～P99 range 拉大就得到高分。

6. Clipping Control

統計靠近黑端 / 白端的 pixel 比例：

Clipping Control = 100 × exp(-ClippingPercent / 3)

高分代表：AGC / Contrast Enhancement 較少造成黑白細節被 clipping。

7. Artifact Control

主要檢查：

  • Halo / Ringing
  • Horizontal / Vertical Seam
  • Repeated Grid / Block Pattern

Artifact Control = 50% × Halo Control + 50% × Seam Control

重複且接近週期性的 seam / grid 會比單一自然物體邊界受到更高懲罰。

8. RAW Total Score

項目權重
Detail Clarity22%
Contrast Quality18%
Flat Cleanliness18%
Thermal Uniformity16%
Clipping Control10%
Artifact Control16%

Total = 0.22 × Detail Clarity + 0.18 × Contrast Quality + 0.18 × Flat Cleanliness + 0.16 × Thermal Uniformity + 0.10 × Clipping Control + 0.16 × Artifact Control

9. Quality Confidence

Quality Confidence 不加入 Total Score，只表示本張影像有多少可用的 Flat / Edge / Region 可支撐本次分析。

建議使用方式：比較 Enhancement 演算法時，盡量使用同一場景、同一 RAW source、 同一 bit depth、相同裁切範圍。Total Score 可用來快速排序，但仍建議同時觀察各子分數， 特別是 Detail Clarity、Flat Cleanliness、Thermal Uniformity 與 Artifact Control。
